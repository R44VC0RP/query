query

Let coding agents ask you for secrets without asking in chat.

When an agent needs an API key, query opens a floating prompt on your Mac. You type the value, and it goes straight to the command. It never lands in the transcript, and the agent never sees it.

Install

$ curl -fsSL https://raw.githubusercontent.com/R44VC0RP/query/main/install.sh | sh

Agent skill

$ npx skills add R44VC0RP/query

macOS 14 or later, Apple silicon and Intel. No permissions needed.

How it works

  1. The agent asks by name. It runs query run OPENAI_API_KEY -- npm test instead of asking you to paste a key.
  2. A prompt floats over your screen. It shows only the key names. Type or paste the values and press Return, or Esc to say no.
  3. The values go where they're needed. The command gets them as environment variables, and the agent gets only its output.

Three ways to deliver

query run KEY -- npm test

Runs the command with the values in its environment. The agent never sees them.

query write .env.local KEY

Merges the values into a dotenv file, readable only by you.

query get KEY

Prints the values for the agent to read. For settings that aren't secret.
